# NeuroScan AI
AI-Assisted Brain MRI Analysis platform for educational and research purposes.

## Warning & Disclaimer
**NeuroScan AI is strictly for educational and research use.** 
It does NOT provide medical diagnosis, treatment prescription, or tumor staging. The predictions generated by the AI classifier are not a substitute for professional medical evaluation.

## Architecture
- **Frontend**: React + Vite + TypeScript + TailwindCSS
- **Backend**: Python 3.11+ (Flask, PyTorch/TensorFlow)
- **Database/Auth/Storage**: Supabase (PostgreSQL, RLS)
- **LLM Service**: Groq API (for educational explanations)

## Project Structure
- `/frontend`: React application
- `/backend`: Flask API & ML integration
- `/database`: Supabase SQL schemas and RLS policies
- `/model`: Scripts for model training and evaluation

## Getting Started

### 1. Supabase Setup
1. Create a project in Supabase.
2. Run the SQL schema found in `database/schema.sql` in your Supabase SQL Editor.
3. Configure the storage buckets `brain-scans` and `reports`.

### 2. Backend Setup
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```
Create a `.env` file in `/backend` using `.env.example` values.

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Create a `.env` file in `/frontend` with your Supabase anon key and URL.

### 4. Running with Docker
```bash
docker-compose up --build
```
